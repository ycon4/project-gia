## Tips for Creating Events

1. **Required Fields (minimum):**
   - Event Title
   - Start Date
   - End Date
   - At least 1 session (or enable Pre-Registration)

2. **Recommended Fields:**
   - Event Type (for better categorization)
   - Mode (affects venue label)
   - Venue (where participants will go)
   - Organizer (for accountability)
   - Target Participants (for planning)

3. **For Poster Generation:**
   - Fill in Event Series Name
   - Add Speaker details
   - Upload Speaker Photo
   - Add Registration Link

4. **For GAD Reporting:**
   - Fill in Budget & Funding Source
   - Add GAD Mandate / Legal Basis
   - Write clear Objectives
   - Update Accomplishment Notes after event

5. **Registration Form:**
   - Always enable: College/Office, Sector, PWD Status (for SDD reporting)
   - Enable Email & Phone for communication
   - Enable other fields based on your data needs

## Common Event Types & Typical Configurations

### Seminar (Half-day)
- Sessions: Pre-Registration, Morning Session
- Fields: College, Sector, PWD Status, Email
- Duration: 1 day

### Workshop (Full-day)
- Sessions: Pre-Registration, Morning, Afternoon
- Fields: All Identity + Contact + Affiliation
- Duration: 1 day

### Training (Multi-day)
- Sessions: Pre-Registration + Day 1-3 (Morning/Afternoon)
- Fields: All fields enabled
- Duration: 2-5 days

### Symposium (Multi-day with parallel sessions)
- Sessions: Pre-Registration, Plenary, Breakout A/B/C, Closing
- Fields: All fields + Year Level (for students)
- Duration: 2-3 days
